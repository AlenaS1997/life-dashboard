# Life Dashboard — итоговый отчёт по проекту

Дата закрытия: 21 мая 2026.

## Что построено

Система оцифровки повседневных метрик Алёны: сон, восстановление, активность,
питание, вес, события календаря — с автоматическим сбором, наглядным
дашбордом на iPhone и аналитическими дайджестами в Telegram.

## Компоненты в продакшене

### Сбор данных

| Источник | Что собирает | Как | Когда |
|----------|--------------|-----|-------|
| Garmin Connect | Сон, фазы сна, HRV, шаги, стресс, Body Battery, отбой/подъём, вес | `garmin_sync.py`, GitHub Actions | 08:05 МСК |
| FatSecret | Калории, БЖУ | `fatsecret_scraper.py` (Selenium), GitHub Actions | 07:00 МСК |
| Google Calendar | События дня | n8n `gcal-sync` | 08:00 МСК |

Все данные складываются в Google Sheets (`garmin_daily`, `fatsecret_daily`,
`gcal_events`, `nutrition_goals`, `health_reminders`).

### Дашборд

PWA на GitHub Pages — https://alenas1997.github.io/life-dashboard/
Открывается в Safari, добавляется на домашний экран iPhone. Вход по паролю.

Блоки: сводка «Сегодня», тренды за 7 дней (с tap-детализацией), питание за вчера
с цветовой индикацией по целям, недельный трекер превышений нормы, вес со
спарклайном и историей взвешиваний, календарный heatmap сна (14/30 дней),
фазы сна, композитный score дня, серии-стрики.

### Telegram-бот `@ms_life_dashboard_bot`

- **Утренний дайджест** (08:30 МСК) — разбор от Claude: что произошло,
  тенденции, связи между метриками, одна рекомендация.
- **Недельный итог** (вс 19:00 МСК) — сводка недели, сильный/слабый день,
  эксперимент на следующую неделю.
- **Напоминания** — пишешь свободным текстом («через неделю — стоматолог»),
  бот распознаёт и сохраняет.
- **Команда `/goal`** — задать целевые КБЖУ прямо из чата.
- **Whitelist** — бот отвечает только разрешённым chat_id.

## Инфраструктура

- **GitHub** — репозиторий `alenas1997/life-dashboard`, GitHub Actions для
  Garmin/FatSecret/Pages.
- **n8n на Railway** ($5/мес Hobby) — оркестрация дайджестов и бота.

- **Google Cloud** — service account для Sheets, OAuth-клиент для Calendar.

## Как поддерживать

- **Cookies FatSecret** живут несколько месяцев. Когда протухнут — workflow
  упадёт с понятным сообщением; обновить через `scripts/fatsecret_export_cookies.py`.
- **Добавить участника в бота** — узнать его chat_id (`@userinfobot`),
  дописать в массив `ALLOWED` ноды Whitelist.
- **Изменить цель КБЖУ** — команда `/goal` в боте.
- Все технические детали и «грабли» — в `CLAUDE.md`.

## Итог

Проект закрыт. Система полностью автономна: данные собираются по расписанию,
